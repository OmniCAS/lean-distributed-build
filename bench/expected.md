# 预期效果：实验 E1–E4 每一格的预期值、容差与当前实测

标记：**预测**（模拟器 + 校准参数，在运行之前给出）、**实测**（`bench/results/` 里的运行记录）。预测怎么算的见 `study/e1_expected.py`、`study/q7_extrapolate.py`、`study/rh_import_sensitivity.py`；校准见 `docs/study-report.md` 第 4.2 节。

## 预测用到的参数（都在运行之前就能量）

| 参数 | 值 | 来源 |
|---|---|---|
| 每个实例的逐模块耗时 | 该实例单机原版 `lake build`（A0）的逐模块秒数 | 实测 |
| 三台机器相对 A0 所在机器的速度 | worker-1 1.022，worker-2 1.438，worker-3 1.122 倍耗时 | 实测（在中图三机运行上量的；宽图上为 1.033 / 1.383 / 1.134，一致） |
| 各 worker 开始干活的时刻 | 13.0、22.4、29.3 秒（单机运行 14.6 秒） | 实测 |
| 每任务在编译之外的开销 | 三机 0.21 秒，单机 0.044 秒 | 实测 |
| 同一机器上两次运行之间每模块耗时的随机差异 | 对数标准差 0.12 | 实测（0.11–0.14） |

每一格跑 10 次带随机差异的模拟，**预测 = 中位数，容差带 = 5%–95% 分位，且至少 ±15%**（一次受最长链限制的运行本身就有这么大的起伏）。
